# 工资表打印格式批量调整工具 (xlwings 版)

## 概述

基于 xlwings（需要本地安装 Excel）的工资表打印格式批量调整工具。自动处理多个 Excel 工资表文件，统一设置打印布局、隐藏指定列、修改签字文本。

## 功能

- 批量处理多个 .xls / .xlsx 文件
- 自动提取单位名称和年月生成新文件名
- 设置页边距（左侧 2cm）
- 设置打印标题行（第 1~5 行）
- 缩放至 1 页宽
- **模式1**：直接隐藏指定列（按列地址或表头名称）
- **模式2**：仅当某列数据全为空时隐藏
- 修改签字文本 `部长、分管副总签字：` → `部长签字：`
- 设置 `制表人：` 单元格居右对齐
- 当社保/医保/工伤/公积金四列基数全为 0 时，自动删除 `业务审核：` 字样
- 文件拖拽添加、进度条显示、详细日志

## 使用方式

```bash
# 安装依赖
pip install -r requirements.txt

# 运行
python XForm_tkinterdnd2_optimized.py
```

**注意**：本工具依赖 `xlwings`，需要在 Windows 系统上安装 Microsoft Excel 才能运行。

## 依赖

- xlwings - 通过 COM 接口操作 Excel（需要安装 Excel）
- tkinterdnd2 - GUI 拖拽支持

## 配置

配置文件 `xform_config.json` 自动生成，包含隐藏列的详细配置（列头行号、列地址、表头名称等），可通过 GUI 界面实时调整。
