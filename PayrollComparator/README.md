# 工资表人员差异对比工具

## 概述

对比两个月的工资表 Excel 文件，自动识别**新增人员**和**减少人员**，并从电话信息表中匹配手机号，生成差异报告。

适用于每月工资核算时快速掌握人员变动情况。

## 功能

- 读取东软格式工资表（自动定位第 6 行开始的数据区域）
- 通过身份证号进行人员比对（上月 vs 本月）
- 从电话信息表中匹配新增人员的手机号
- 生成 Excel 差异报告（含花名册、减少人员、电话缺失三个 sheet）
- 支持 GUI 图形界面（文件拖拽）和命令行模式
- 自动保存配置和上次使用的电话信息表路径

## 使用方式

### GUI 模式（默认）

```bash
python PayrollComparator.py
```

### 命令行模式

```bash
python PayrollComparator.py -p 上月工资表.xlsx -c 本月工资表.xlsx -t 电话表.xlsx -o 差异报告.xlsx
```

参数说明：
| 参数 | 说明 |
|------|------|
| `-p, --prev` | 上月工资表文件路径 |
| `-c, --curr` | 本月工资表文件路径 |
| `-t, --phone` | 电话信息表文件路径（可选） |
| `-o, --output` | 输出报告文件路径（可选） |
| `--gui` | 强制启动 GUI 模式 |

## 依赖

- pandas - 数据读取和处理
- openpyxl - 生成 Excel 报告
- tkinterdnd2 - GUI 拖拽支持（可选，命令行模式不需要）

## 文件说明

- `PayrollComparator.py` - 主程序（含 GUI 界面）
- `prcomp.py` - 简化版（布局修复版本）
- `config.json` - 配置文件（自动生成）
